# Calculate KDRI 2019

Calculate KDRI 2019

## Usage

``` r
calc_kdri2019(
  donor_age_year,
  donor_height,
  donor_hypertension,
  donor_sex,
  donor_cmv,
  donor_egfr,
  donor_days_in_hospital
)
```

## Arguments

- donor_age_year:

  Donor age in years

- donor_height:

  Donor height in cm

- donor_hypertension:

  Donor hypertension status ("YES"/"NO")

- donor_sex:

  Donor sex ("MALE"/"FEMALE")

- donor_cmv:

  Donor CMV status ("Positive"/"Negative")

- donor_egfr:

  Donor eGFR

- donor_days_in_hospital:

  Days in hospital

## Value

KDRI 2019 score
