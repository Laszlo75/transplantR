# Calculate KDRI 2012

Calculate KDRI 2012

## Usage

``` r
calc_kdri2012(
  donor_age_year,
  donor_hypertension,
  donor_weight,
  donor_days_in_hospital,
  donor_adrenaline
)
```

## Arguments

- donor_age_year:

  Donor age in years

- donor_hypertension:

  Donor hypertension status ("YES"/"NO")

- donor_weight:

  Donor weight in kg

- donor_days_in_hospital:

  Days in hospital

- donor_adrenaline:

  Adrenaline use ("YES"/"NO")

## Value

KDRI 2012 score
